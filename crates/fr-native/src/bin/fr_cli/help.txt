Detailed help:
  fr help connect         Connection, discovery, privacy and saved-host options below.
  fr help robot           Robot command overview and explicit owner modes.
  fr help robot session   Foreground lifetime, local identity and conditional close.
  fr help robot observe   One-shot observations, retained views and screenshots.
  fr help robot input     Original-observation actions and staged effect receipts.
  fr help send            Later file selections, status, pause, resume and cancellation.
Use a command path alone with --help, for example fr robot input --help.
Help reads no local service or desktop and accepts no target or operational options.

Discovery and connection:
hosts/peers read one local machine snapshot; peers never probes remote services.
On macOS these commands read the installed Tailscale app, or without it the
open-source tailscaled's /var/run/tailscaled.socket; --socket PATH selects one
root tailscaled socket. Native connection/desktop commands need macos-desktop.
Doctor diagnoses installed Tailscale status, service port collisions, and certificate lifecycle.
Doctor --probe-native separately captures one local root-display picture and tries
the explicitly selected HEVC encoder; --input-agent adds capability discovery with
no injected input. It runs before any runtime/tailnet access, kills and reaps its
bounded probe children, and reports scoped results plus actionable failures.
No backend fallback, decoder/presenter proof or sustained-performance claim.
Use an explicit local X display and installed worker; worker/cookie paths and
captured content are never printed. Exit 1 means a requested probe failed or was
blocked; other capabilities stay not_tested. Tailnet options cannot be combined.
Discovery/inspect uses installed Tailscale metadata. --by-name requires an exact
canonical tailnet FQDN, never arbitrary DNS/a URL. --probe reads authenticated frd
capabilities, opening no approval, observation or input; it grants no access.
hosts --probe: up to 64 peers in stable-ID order, four concurrently, one 20-second
discovery/probe budget, five seconds/probe.
Refusals/unstarted peers/omissions stay visible; timeout cannot prove offline.
--trust-roots defaults to /etc/ssl/certs/ca-certificates.crt; --worker defaults
to fr-media-worker beside fr. Each connection rechecks identity and strict TLS.
Displays requires configured host approval. --display only refuses multiple
displays; choose opens a chooser per approved connection. On Linux, --fit uses CPU
nearest-neighbour fitting in a fixed local window. On macOS, it bounds AppKit
content points with Metal aspect fitting. Remote size is unchanged.
Omit it for native pixels. Set local XAUTHORITY when required.
Native transport/media remain unqualified. Close the window/Ctrl-C to stop.

Native machine picker:
--choose-host immediately replaces NODE_ID after connect. The local X11 window
lists up to 1024 installed-Tailscale peers by canonical name. Arrows move;
Page Up/Down/wheel pages; Home/End jumps. Release Enter/left button to choose;
Esc/window close/Ctrl-C cancels. Names/IDs/route hints promise no access.
Choice expires after 120 seconds; cleanup precedes connection/file selection.
--choose-host excludes --saved/--hosts-file/--by-name and robot commands.
--json emits host_selected before connecting; use its ID for disconnect.

Control and reconnect:
Choose one role. --control requests input once after a fresh frame; host:
frd run --input-agent. Input: keys, buttons, absolute pointer, line-wheel;
no text/pixel-scroll. Refusal, revocation, expiry and local release are terminal.
After transient failure or a checked host geometry change, --attempts may
reconnect VIEWING ONLY after proven cleanup. Control/clipboard/files never repeat.
In a --control viewing window, press and release F8 for a new control request.
Ctrl+Alt+Shift+F7 reopens with the display picker; a window resize reopens viewing
at the new size. Both end input, clipboard and file choices.
--capture-system-shortcuts (--control, Linux X11) grabs the keyboard after the
grant for Alt+Tab and similar shortcuts; the title identifies this mode.
Ctrl+Alt+Shift+Escape releases locally. Focus/input fences release the grab.
Without it shortcuts stay local; unavailable capture ends control with
system_shortcuts_unavailable. Reserved X-server shortcuts remain limited.

Clipboard:
--control defaults to UTF-8 sharing with linux-clipboard on Linux, or with
macos-desktop on the Mac client:
1 MiB/item, after control and visible privacy controls. --no-clipboard disables;
--clipboard selects the default. Use Turn Off in the Mac viewer toolbar or
turn off/close either Linux Clipboard sharing window to end sharing. Missing
permission/support is typed absence; desktop continues. Mac hosting does not
offer a clipboard backend yet.
An incomplete transfer unable to stop independently closes the connection.
View-only never accesses clipboard.

Files:
On macOS, --choose-files opens a native picker before connecting: up to 8 local
files/folders for the original --control upload, instead of --send paths.
Cancel/timeout opens no connection; reconnect never repeats the choice.
--send PATH needs --control and host frd run --files DIR: up to 8 regular files
or portable directory roots, in order. Symlinks/special files/existing names
refuse; empty items survive. The upload panel separates progress/receipts: Pause /
Resume / Cancel. Closing hides it; accepted work continues. Pause cannot extend expiry.
With viewer focus, physical Ctrl+Alt+Shift+F8/F9/F10 pause/resume/cancel only the
original --send selection. Release each key; ambiguous keys disable shortcuts.
An open panel accepts X11 file-manager Copy drops. --file-drop works without
--send: wait for Ready to send files. Local file URIs/Copy only; 8 selections/batch,
8 retained batches, original cumulative limits. Complete one drop before the next;
use panel buttons. Hiding stops drops; Cancel before the first ends sharing.
Reconnect never restores drops/repeats selections. Missing controls:
file_drop_unavailable.
--receive DIR must be absolute, owned by you, not group/other writable, with no
symlink components. Host: frd run --once --input-agent PATH --send PATH... .
Items publish atomically, never open/run. Defaults: 256 MiB/selection, 1 GiB/session.
Both --receive-max-* limits must be positive; session >= file. Directories count total content; cancelled admitted attempts
spend budget. --receive-conflict reject is default; keep-both uses a bounded
.fr-conflict- name. Neither overwrites, merges, retries or resumes.
Download Cancel affects only downloads.
Upload/download may coexist with clipboard/audio; legacy peers may admit one
direction. Permissions/limits/cancellation remain separate under the original
control lease. Receipts report index/size/durability/cleanup, never paths;
progress does not prove publication.

Playback audio:
--audio requests playback in either role; host: frd run --audio; builds: linux-audio.
Missing support is typed absence; video continues.
Output uses --audio-server, else PULSE_SERVER, else $XDG_RUNTIME_DIR/pulse/native,
and the default sink or --audio-sink. --audio-volume: local 0..100 (default 100);
--audio-muted starts muted. Remote audio offers Quieter/Louder/Mute / unmute.
Settings survive recovery/reconnect/panel close. Changes affect new submissions;
queued sound drains briefly. Host, microphone and system volume stay unchanged.

Microphone:
--microphone requires --control and an explicit --microphone-source NAME.
Client build: linux-desktop,linux-microphone with fr-audio-worker beside fr.
The host must independently enable and approve its native microphone endpoint.
The local Microphone panel starts muted: click Talk to authorize this selected
source, then wait for the host configuration and actual PulseAudio RECORD access.
Mute stops this talk generation. Turn off, hiding or closing the panel ends this
microphone choice. Both ends require visible controls; no recording starts from
connecting, receiving playback, restoring permission or viewing reconnects/F8.
After a mute, wait for the old capture child to exit before another explicit Talk.
The panel needs visible space outside the viewer; --fit can leave room.
Server: --microphone-server, else PULSE_SERVER, else XDG_RUNTIME_DIR/pulse/native.
Only a local Unix socket and named source are accepted, with no default-source
alias, source creation, implicit device change or downloaded worker.
Reports distinguish native capture from host application audibility; physical
microphone/live-tailnet qualification remains separate. Missing host selection
is typed absence. Unsafe pending output may end the original connection.

Local foreground sessions:
disconnect TARGET / robot session close TARGET stop the kernel-authenticated
same-user owner for the exact target. Closure proves local cleanup, not remote
release/rollback; host reports stay in the connect result.
session status contacts neither Tailscale nor the host; remote state is unknown.
connection_id is not a remote session or input lease. close --connection-id ID
refuses a replacement with local_session_changed; it survives viewing reconnects
but not a new invocation. Omit it to stop the current owner. Lost replies remain
unknown_external_effect; do not retry another invocation.
session open TARGET --foreground --role view|control uses the native owner/options,
TLS, approval and display selection. It requires a local desktop and runs until
shutdown, reporting completion, never an opened lease. Inspect/close from another
process; detached opens are unavailable. Robot input requires --accept-input and
original connection/lease/observation handles.

Saved local hosts:
fr hosts save ALIAS NODE_ID [--port PORT] [--hosts-file PATH] [--socket PATH] [--json]
fr hosts saved [--hosts-file PATH] [--json]
fr hosts forget ALIAS [--hosts-file PATH] [--json]
fr connect ALIAS --saved [--hosts-file PATH] [connect options above]
fr displays ALIAS --saved [--hosts-file PATH] --experimental-native [display options]
fr inspect|disconnect ALIAS --saved [--hosts-file PATH] [their other options]
ALIAS is 1..64 lowercase letters, digits, '.', '_' or '-', starting alphanumeric.
Saving resolves/stores stable node ID and exact canonical TLS name/port via
installed Tailscale, never addresses/permissions. Connections recheck identity;
rename/reassignment refuses until resaved.
--saved cannot combine with --by-name or --port. Without it, targets remain node IDs.
Profiles: $XDG_CONFIG_HOME/franken_remote/hosts.json, else
$HOME/.config/franken_remote/hosts.json. Local list/forget needs no Tailscale.
Private atomic storage: 100 entries/128 KiB; symlinks/duplicates/malformed profiles
refuse. Saving never contacts frd or enables hosting.
